# MERN Todo App

This is a modern full-stack MERN Todo application built using React.js, Node.js, Express.js, MongoDB, Mongoose, and JWT Authentication. The project is designed as a complete productivity management system with secure user authentication, task tracking, analytics, and a clean modern UI that feels like a real SaaS product instead of a basic CRUD application. Users can create an account, log in securely, and manage their personal tasks with features such as adding tasks, editing tasks, deleting tasks, marking tasks as completed or incomplete, filtering tasks, searching tasks, setting priorities, and tracking overall productivity progress.

The application includes a dynamic analytics dashboard that visually shows total tasks, completed tasks, pending tasks, and overall completion percentage using graphs and progress indicators. If all tasks are completed, the system displays a 100% completion state with celebration effects to improve user experience and motivation. The frontend is fully responsive and designed with smooth animations, modern layouts, interactive cards, elegant typography, and user-friendly components to provide a professional productivity-app feel similar to platforms like Notion or Todoist.

The backend is built with Express.js and MongoDB using Mongoose for database management. Authentication is implemented using JWT tokens and bcrypt password hashing to ensure secure login and signup functionality. Protected routes and middleware are used to secure APIs and user data. The project follows a clean folder structure with separate directories for controllers, routes, middleware, models, services, and reusable frontend components, making the application scalable and production-ready.

This project demonstrates full-stack development concepts including REST APIs, authentication systems, CRUD operations, database integration, state management, responsive UI design, and real-world project architecture. It can be used as a learning project, portfolio project, or a base for building larger productivity management applications in the future.

Tech Stack Used: React.js, Vite, Node.js, Express.js, MongoDB, Mongoose, JWT, bcryptjs, Axios, and Chart.js/Recharts.
